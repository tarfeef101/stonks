## Decisions

| ID | Date | Decision | Rationale / notes |
|----|------|----------|-------------------|
| D-001 | 2026-11-02 | **Docker-only toolchain:** all build/test/lint/fmt/migrate/tf-validate work runs in container images (`golang:1.27.3`, `node:26.13.0`, `hashicorp/terraform`); no host toolchain installs; nothing lands on the host PATH | User directive (2026-11-02). Host prerequisite: docker + compose (already present). testcontainers integration tests run in the `golang:1.27.3` container with the host `docker.sock` mounted so tests spawn their own ephemeral containers (standard CI pattern; no host modification). |
| D-002 | 2026-11-02 | Go module path = `finance-tracker` (single element) | Repo is self-hosted (gogs; no public VCS URL at execution time); a single-element module path is legal for a never-fetched module and avoids inventing a domain. |
| D-003 | 2026-11-02 | Node pinned to **26.13.0** (Active LTS line 26; latest 26.x as of 2026-11-02 per nodejs.org dist index) | Plan §1 requires the exact 26.x minor be recorded at first use; `node:26.13.0` is the image tag. |
| D-004 | 2026-11-02 | `hashicorp/terraform` image tag stays `latest` until step 1.1 | Exact version verified + pinned at step 1.1 (first `tf-validate` run); recorded here then. |
| D-005 | 2026-11-02 | New Relic `go-agent/v3` pinned **v3.45.0**; init is `app, err := newrelic.NewApplication(opts...)` (returns an error on bad config), options use the `Config*` prefix (`ConfigAppName`, `ConfigLicense`, `ConfigEnabled`, …); HTTP instrumentation is the nil-safe `_, handler := newrelic.WrapHandle(app, pattern, handler)` (returns `(string, http.Handler)`); with no license the agent is disabled explicitly via `ConfigEnabled(false)` | Verified in module source: `Config.validate()` rejects an empty license while `Enabled` is true (default) with `errLicenseLen`, so no-license runs must pass `ConfigEnabled(false)`; `AppHTTPHandler` and `NewLogLogger` no longer exist in v3.45.x. |
| D-006 | 2026-11-02 | `prometheus/client_golang` pinned **v1.25.0**; process collector is `prometheus.NewProcessCollector(prometheus.ProcessCollectorOpts{})` | Type renamed from `ProcessOpts` (v1.25); verified in module source before wiring into `/metrics`. |
| D-007 | 2026-11-02 | Backend dependency set at first `go get`: chi **v5.5.0**, pgx/v5 **v5.12.0**, prometheus/client_golang **v1.25.0** (D-006), newrelic/go-agent/v3 **v3.45.0** (D-005) | All latest as of 2026-11-02; minor bumps may land with later `go get`s (goose, cron, testcontainers-go at their first-use steps). |
| D-008 | 2026-11-02 | NR `@newrelic/browser-agent` **1.324.1** (no SPA variant exists on npm): class-based API `new BrowserAgent({ info: { licenseKey, applicationID } })` — loader code executes **immediately on instantiation** (there is no `init()`/`load()`); available API: `addPageAction`, `setPageViewName(name, host?)`, `setCustomAttribute`, `setUserId`, `recordCustomEvent`, `noticeError`; `soft_navigations` is built in and auto-starts. The built-in `isValid(info)` requires `licenseKey && applicationID` (errorBeacon defaults), so incomplete config = built-in no-op; we still gate on both `PUBLIC_NR_*` env vars being set. **No `app_name`/`distribution` option exists in this version** — the browser app is identified by `applicationID` alone (`PUBLIC_NR_APP_NAME` dropped). | Verified against installed `dist/types` (AgentOptions/Info/Init) + README. `setPageViewName(page.url.pathname)` per route keeps NR views aligned with client-side routes. |
| D-009 | 2026-11-02 | Frontend scaffold + tooling: `sv` **1.2.0** CLI (`create-svelte` is deprecated): `sv create . --template minimal --types ts --no-add-ons --no-install --no-dir-check`, then `sv add eslint prettier` (non-interactive with explicit args) → flat `eslint.config.js` + `prettier.config.js` (tabs, single quotes, no trailing commas, printWidth 100, svelte + tailwindcss plugins); scripts `lint` = `prettier --check . && eslint .`, `format` = `prettier --write .`. **SvelteKit 3 breaking changes hit at wiring and fixed:** (1) `$lib` removed → `#lib` via package.json `imports`, plus explicit `paths` in `tsconfig.json` so extensionless `#lib/*` resolves (generated tsconfig lives at `node_modules/$app/tsconfig.json` with empty `paths`); (2) `svelte.config.js` no longer supported — SvelteKit config incl. adapter lives in `vite.config.ts` via `sveltekit()`, `@tailwindcss/vite` in top-level `plugins`; (3) `<slot>` deprecated → Svelte 5 snippets (`children: Snippet` + `{@render children()}`); (4) internal `<a href>` must use `resolve()` from `$app/paths` (eslint `svelte/no-navigation-without-resolve`). Also: the eslint/prettier add-on's default `tailwindStylesheet` (`./src/routes/layout.css`) is wrong → pointed at `./src/app.css`; prettier v3 does not read `.gitignore` → `/build/` + `/.svelte-kit/` added to `.prettierignore`. SPA serving verified: nginx `try_files $uri $uri/ /index.html` gives 200 + identical shell on deep routes (`vite preview` in SK3 runs the **built SvelteKit server** — route matching, responses carry `x-sveltekit-page: true` — not a plain static file server: registered routes serve 200 (SSR), unregistered deep paths 404 with the full app shell (bootstrap JS included) so the client-side router takes over; the production 200 deep-link fallback is nginx `try_files`. An initial `spaPreviewFallback()` vite plugin that rewrote extensionless paths to `/index.html` broke the registered `/` (SK has no such route) — dropped; no custom preview fallback needed). Locked FE versions (registry-verified 2026-11-02 in node:26.13.0): kit **3.1.1**, svelte **5.57.3**, adapter-static **4.0.1**, vite **8.3.5**, typescript **6.0.3** (kit 3 peer is `^6.0.0` — TS 7.x incompatible), @tanstack/svelte-query **6.3.8**, svelte-i18n **4.0.1**, tailwindcss + @tailwindcss/vite **4.3.3**, eslint **10.14.0**, prettier **3.9.10**, NR browser agent **1.324.1** (D-008). svelte-i18n v4 runtime: `init({ fallbackLocale, initialLocale })`, `register(locale, loader)`, `waitLocale()`, `_` = `$format` store, no standalone `setLocale` (the `locale` store is writable). `nginx:alpine` resolves to **nginx 1.31.8**. | Scaffold + wiring verified: `make frontend-build`/`frontend-lint`/`frontend-fmt` green; `finance-tracker/frontend:local` image healthcheck healthy; `/` and deep routes 200; `/_app/` assets served `Cache-Control: public, max-age=31536000, immutable`. |
